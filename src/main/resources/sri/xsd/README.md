# SRI official XSD resources

Place the official invoice XSD here before enabling real Phase 11.4 validation in runtime:

```text
src/main/resources/sri/xsd/factura_V2.1.0.xsd
```

Download it from the official SRI Facturación Electrónica page under:

```text
Esquemas XSD Y XML Tipo de documento Factura – Versión 1.0.0 – 1.1.0 – 2.0.0 – 2.1.0.
```

This phase intentionally does not ship a handcrafted replacement for the official SRI XSD.
